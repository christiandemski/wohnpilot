# Mockups

Die Dateien sind Design-Mockups aus der Claude-Leinwand (Format `.dc.html`). Sie laufen nur dort interaktiv; hier dienen sie als Referenz für Aufbau, Texte, Maße und Zustände. Farben sind darin noch als Hex-Werte notiert – in der App immer die Tokens aus `docs/design/tokens.css` verwenden.

| Datei | Screen | Hinweise |
| --- | --- | --- |
| `Uebersicht.dc.html` | Übersicht | Als-Nächstes-Karte, Bento (Strom, Frist-Ring), Diese Woche, Tab-Leiste |
| `AbleseRunde.dc.html` | Ablese-Runde | Rollenzähler mit Logik im `<script>`-Block (Differenz, Plausibilität, pro Tag) |
| `ZaehlerDetail.dc.html` | Zähler-Detail | Stand, Segmentschalter, Monatsdiagramm mit Vorjahr, Hinweis zur Nachzahlung |
| `erster-entwurf/Erfassen.dc.html` | Erfassen-Sheet | Struktur übernehmen, Look nach Designsystem |
| `erster-entwurf/Vertrag.dc.html` | Vertrag-Detail | Fristen-Lineal, Vertragsdaten, Preiserhöhungs-Hinweis |
| `erster-entwurf/Einrichtung.dc.html` | Einrichtungsassistent | Schritte und Auswahl-Logik im `<script>`-Block |
| `erster-entwurf/Kiosk.dc.html` | Kiosk | Drei Kacheln, immer dunkel |

Alle Zahlen in den Mockups sind Beispielwerte.
